# Original Vancouver street material library

Five procedural, seamless 1024×1024 material sets. Every pixel is generated by the included deterministic Python source; no photos, stock material, AI-generated reference image, or third-party artwork is used. Original code and artwork are available under MIT. These are plausible material studies, not surveyed replicas of particular real façades.

| Prefix | Physical tile size | Content |
|---|---|---|
| `brick-charcoal` | 1.728×1.728 m | Dark fired brick, 8 running-bond units across × 24 courses |
| `brick-terracotta` | 1.728×1.728 m | Warm red-brown brick with muted mortar |
| `asphalt-fine` | 3×3 m | Fine aggregate road asphalt; no baked lanes |
| `sidewalk-concrete` | 3×3 m | Four 1.5 m square concrete slabs and expansion joints |
| `facade-glass` | 12×12 m | Four bays × four storeys, each 3 m; split panes and spandrels |

Each prefix has `-albedo.png`, `-roughness.png`, and `-normal.png`. Glass also has `-night-emissive.png`; use only in night lighting. `materials.json` records map names, physical sizes, normal strength guidance and deterministic seam diagnostics. `material-preview.jpg` shows each material repeated 2×2 to expose tile seams.

## Three.js integration notes

- Albedo and emissive maps: `texture.colorSpace = THREE.SRGBColorSpace`.
- Roughness and normal maps: leave `THREE.NoColorSpace`; these are data textures.
- Normals use tangent-space OpenGL **+Y** convention.
- All maps: `wrapS = wrapT = THREE.RepeatWrapping`. Use mipmaps and anisotropy up to 8 or the device maximum.
- For merged walls, write mesh UVs in **metres** (U = distance along the wall, V = height above building base), then set shared map repeat to `(1 / tileWidthMeters, 1 / tileHeightMeters)`. This preserves real brick/window sizes across buildings without a separate texture instance per façade.
- If each face instead has normalized 0–1 UVs, its texture repeat must be `(faceWidthMeters / tileWidthMeters, faceHeightMeters / tileHeightMeters)`.
- Normal-scale starting values: brick `(0.7,0.7)`, asphalt `(0.35,0.35)`, sidewalk `(0.5,0.5)`, glass `(0.35,0.35)`.
- Glass roughness is low for panes and higher for metal/spandrels. Use metalness 0–0.15 and a real scene environment/reflection source. Do not fake mirror glass with high metalness.
- Asphalt is a surface finish: actual road crown, lane markings, curbs and drains should be separate geometry/decals. Sidewalks must remain raised objects.
- For convincing street views, texture maps supplement projecting façade details, window reveals, storefronts, lamps, doors and trees. They do not replace geometry.

Regenerate with Python 3, NumPy and Pillow:

```sh
python3 generate_textures.py
```

Noise is sampled periodically; mortar and façade units fit integer repeats. Opposite edge pixels need not be identical: they are adjacent samples across a wrapped surface, with the same continuity as interior neighbors.
