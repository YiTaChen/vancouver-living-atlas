# 城市音景：操作、資源上限與驗證（2026-10-22）

本次加入可選的城市音景：腳步、岸邊浪聲、公園鳥鳴、海鷗、港口低鳴／短笛，以及附近和搭乘中的 SkyTrain。全部以 Web Audio 即時合成，是原創、示意性的遊戲聲音；沒有下載或打包外部音檔，也不是現場錄音、即時船舶資訊或精確列車聲學重建。

## 操作與音訊授權

在 **Layers／圖層** 開啟 **City sounds／城市聲音**，並調整城市音量。觸控裝置由工具列進入圖層設定。控制項、音量標籤及失敗提示提供十種介面語言；開關可用鍵盤操作，觸控列及音量區保留適當操作高度。

每次重新載入預設關閉。建立引擎、顯示設定、切換語言或重新打開面板都不會建立 AudioContext；只有使用者操作開關的事件會呼叫 `setEnabled(true)`。不從 localStorage 自動啟用聲音。啟用失敗會保留關閉狀態並提示重試，遊戲畫面仍可使用。

這個音量控制城市音景。既有車輛面板的選用撞擊／摩擦音效沿用自己的開關；兩者沒有被默默改成同一授權或音量設定。

## 聲音如何選擇

| 聲音 | 依據與範圍 |
| --- | --- |
| 腳步 | 使用人物腳底的實際位置變化，拒絕靜止、模式／空間切換、異常跳躍及超過 500ms 的取樣間隔，不用相機移動或經過時間產生步數。坐下及停靠公車內不產生腳步。 |
| 地面差異 | 海灘、公園與既有 wood／boardwalk surface 標記選擇沙地、草地、木面或一般鋪面；車廂步行使用金屬音色，車站使用鋪面音色。這是已有區域／表面資料的近似分類，不宣稱逐個可見材質的聲學辨識。 |
| 海浪與海鷗 | 使用現有 shoreline 的有限距離查詢及相機海拔；超過約 180m 不發聲。浪聲有輕微的連續起伏；海鷗為間歇短音。 |
| 公園鳥鳴 | 白天、公園範圍及相機相對地面高度共同限制；高空或夜間不持續播放公園鳥叫。 |
| 港口 | 三個原創示意區域，以三維距離漸弱；跟隨港口圖層。不是從任意可見船隻推測的即時來源。 |
| SkyTrain | 一般城市列車只選可見、附近且啟用圖層的 SkyTrain；最多混合三個。音色隨速度變化，左右方位隨相機旋轉。搭乘服務使用當前列車；乘客在移動車廂內站著時不會因列車前進而產生腳步。 |

相機靠近既有室內地板高度、位於地下車站、搭乘車廂或停靠公車時，外部音景會漸弱。僅位於建物的平面輪廓上空不算室內。已開始播放的鳥鳴／海鷗／港口短音經過共用室外 bus 淡出；腳步與自己搭乘的列車聲不套用該室外 bus。

室內判定與地面音色仍是有限的遊戲近似，沒有做逐牆遮蔽、聲音反射、混響求解或完整聲學射線追蹤。

## 執行時與資源

- `lib/city/city-soundscape.ts` 擁有 AudioContext、節點、淡入淡出及生命週期，不讀取城市 mesh。
- `lib/city/soundscape-policy.ts` 是可在 CPU 測試的距離／方位／步伐政策。時間是 `performance.now()` 的毫秒；速度是 m/s；座標與距離是遊戲公尺。
- `lib/city/city-soundscape-world.ts` 在啟用後才建立岸線空間桶，200ms 取樣一次環境資料，每個有效 frame 讀取人物腳步位置。關閉時不讀取地理資料、相機或建立岸線索引。岸線查詢只處理附近九個 200m 格子，保留原始線段的距離計算。
- SkyTrain 的 `soundscapeFootsteps` 在車上提供 carriage-local 腳底位置，在車站提供對應站內位置；空間 token 隨模式／站點／樓層改變。既有行走與碰撞仍由原控制器負責。
- 最多五個延遲建立的 noise loops：海浪、港口及三個列車；最多八個同時存在的短音。沒有全城聲源節點、audio worker、fetch、額外 GPU pass 或音檔解碼。
- 共用一份兩秒、12kHz、單聲道 Float32 noise buffer，共 24,000 samples／96,000 bytes。這是 buffer 的資料大小，不是整個 AudioContext、瀏覽器音訊執行緒或裝置記憶體實測。
- 零增益循環在淡出後約 1.2 秒移除。音量為零時清理所有音訊節點；關閉開關另外關閉 AudioContext。
- 分頁隱藏、BFCache 暫停及獨立車廂展示會清理音訊節點並 suspend；恢復重設腳步與間歇聲音時基，不補播背景期間的事件。銷毀或 WebGL context loss 的引擎清理會關閉音訊並解除 visibility listener。

```ts
soundscape.enabled;                 // 世界 adapter 使用的快速 guard
soundscape.snapshot;                // 狀態及實際節點／buffer 計數
await soundscape.setEnabled(true);  // 只從使用者開關事件呼叫
soundscape.setVolume(0.65);
soundscape.setPageActive(false);
soundscape.update(frame);
soundscape.dispose();
```

音訊未授權、啟用失敗、尚未 running 或已銷毀時，`update` 不配置發聲節點。非有限 listener／時間會清理舊音源。非同步啟用晚於靜音或銷毀完成時，不會重新建立節點。相機 yaw 採 Three.js 世界 Y 旋轉：零度面向 −Z，右方向為 `(cos(yaw), 0, -sin(yaw))`。

## 自動驗證與邊界

以下 **15 項針對性測試通過**，對應新增程式與測試亦完成嚴格 type-aware lint：

```sh
node --test tests/soundscape-policy.test.mjs tests/city-soundscape.test.mjs tests/city-sound-controls.test.mjs tests/city-soundscape-world.test.mjs
```

- 距離連續衰減、室內比例、三維距離、相機左右方向、附近列車上限。
- 實際位移產生步伐；相機移動、列車載運、坐姿、teleport、時間倒退及長間隔不產生補播。
- 未操作不配置 context；靜音／暫停／銷毀清理；非同步 resume 與取消的競態；不支援音訊時可恢復的失敗結果；零音量不建立節點；密集輸入仍遵守聲源上限。
- 十語系標籤、預設關閉、volume 範圍、未就緒狀態及本地化失敗提示；render 不呼叫啟用。
- 岸線格子查詢與逐段投影在負座標、格子交界、長斜線、退化線段及 180m 截止的一致性；關閉時零地理讀取；環境 5Hz 與腳步逐 frame 的分離。
- 使用實際 `SkyTrainTravel` getter 連接世界 adapter／步伐政策，確認車廂世界移動不變成步伐，車廂內局部步行能發出金屬步伐、坐下及停用輸入會停止。
- 外部列車的隱藏、類型、距離及圖層篩選；高空建物輪廓不誤算室內；第三人稱相機跨越草地不改變人物腳下音色。

這些測試使用 Web Audio mock 驗證節點與生命週期，使用真實幾何函式／類別 getter 驗證政策與整合；不等同實際聽覺品質、喇叭／耳機輸出、Safari／手機硬體或整體效能已通過。瀏覽器互動、主觀音量／音色、實機成本與整體正式建置狀態，應依本次交付的獨立驗收紀錄判定，不把 CPU mock 結果延伸為全平台保證。
