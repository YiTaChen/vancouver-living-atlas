# 原創光色實驗室 · 2026-09-30

這一階段把既有 Science World 示意室內空間變成一個能走近、操作、觀察結果、完成挑戰並保留紀錄的活動。活動是 Atlas 原創設計，不宣稱重現 Science World 的官方展項、實際內部動線或科學課程。

## 遊玩流程

城市探索手帳新增光色實驗室卡片。開始活動會移至既有入口；玩家必須依序步行穿過入口大廳與連接圓頂的開口，最後走到既有綠色展示台旁。金色場景標記與區域地圖沿用既有系統，和街道探索路線互斥。

在展示台旁操作紅、綠、藍三個強度滑桿，依序調出黃光、青光與白光。滑桿提供 0–100% 強度，每格 5%；視覺預覽從線性 RGB 強度轉為顯示用 sRGB。三題以各通道相差不超過 8 個百分點為通過條件，按「測試混光」才記錄成功。錯誤配方保留操作狀態並給提示，不扣分；完成後保留三段觀察說明及一枚永久實驗室印章。

實際 3D 展示台上的原創螢幕同步顯示相同混光。它取代該展示台原先的環形與圓柱裝飾；沒有新增即時燈源或陰影。螢幕採小型畫布貼圖，外框合併到既有結構批次。資源由 PublicInteriors / CityEngine 的既有場景生命週期處理。

## 空間與狀態界線

- 動線使用既有 Science World 地方座標：`[40,-59] → [40,-35] → [40,-22] → [20,-22] → [13,-16]`，入口到操作點約 66 公尺。
- 開始前，每 0.3 公尺抽樣動線與左右 0.35 公尺偏移，檢查室內地板、傢俱碰撞與 live navigation。
- 各導引點必須依序靠近 2.5 公尺內，且累計的連續實際步行位移足夠；直接被放到展示台不會取得操作資格。
- 操作必須位於最終點 3 公尺內、步行模式、Science World 的有效地板上，導航高度必須接近室內地板加 1.25 公尺。
- 模式切換、錯誤高度、大幅座標跳躍或隱藏分頁期間的位置改變，會撤銷本次參觀資格。已完成的實驗不受影響；可回入口重新走入。
- 每次調整與提交答案都重新檢查 live navigation；引擎已釋放或 WebGL context 已遺失時不能開始或得分。
- 儲存只包含實驗進度與永久印章，使用獨立、版本化的 `vancouver-atlas-light-lab-v1`。重新載入後仍需完成新的一次實體參觀才能操作。
- 手帳仍保留原本 3 條街道路線／9 篇筆記／3 枚**散步印章**；實驗室印章另行顯示，不混淆既有計數。

## 科學內容來源

配方採用加色混光的基礎關係：紅＋綠為黃、綠＋藍為青、等強度紅綠藍合為白。內容說明與關卡文字是原創摘要。

- [Exploratorium — Colored Shadows](https://www.exploratorium.edu/snacks/colored-shadows)
- [UCSB Physics Lecture Demonstrations — Additive color mixing](https://web.physics.ucsb.edu/~lecturedemonstrations/Composer/Pages/80.45.html)

這些來源支持混光原理，不表示來源機構或 Science World 認可此遊戲活動。

## 程式驗證與可重現入口

`node --test tests/light-lab.test.mjs` 包含 10 個行為測試：不可信存檔、入口動線與碰撞、依序實走、非步行／高度／隱藏／跳躍拒絕、重新載入與重複獎勵、離開操作範圍、引擎終止與位置身份、線性光轉換，以及互動時面向實體展示台但不移動角色。

正式程式不含自動行走按鈕。開啟 `VANCOUVER_VISUAL_QA=1` 的診斷建置可使用 `Lab walk to next marker`：只設定面向並按住既有前進控制，使用原本的速度、碰撞與導航，抵達下一點後放開；不直接改寫位置、不提交答案。每段最長 30 秒；分頁隱藏、模式／地板變更、路徑中斷均停止。

瀏覽器完整遊玩與手機版面證據由本階段主驗證紀錄另外記錄；本文件的單元測試敘述不等同於實際手機硬體效能驗證。
