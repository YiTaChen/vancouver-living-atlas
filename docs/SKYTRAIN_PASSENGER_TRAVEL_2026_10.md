# SkyTrain 七站搭乘整合與驗收（2026-10-22）

本次把離線車站與車廂資產接入城市，提供人物進站、站內行走、候車、上車、沿地理路線移動、停站下車、Waterfront 轉乘及返回街道的完整流程。「搭乘 SkyTrain」與原有靜態車廂展示各自獨立。

## 路線與範圍

| 路線 | 本區域站序 |
| --- | --- |
| Expo Line | Waterfront → Burrard → Granville → Stadium–Chinatown → Main Street–Science World |
| Canada Line | Waterfront → Vancouver City Centre → Yaletown–Roundhouse |

七站均可作為起點或目的地，支援雙向及途中停站。Vancouver City Centre 與 Granville 是不同車站。跨線旅程在 Waterfront 下車、回大廳、換月台再上車；沒有建立 Granville／City Centre 的站內付費區捷徑。本區域兩個邊界站並不代表真實路線終點。

站序與辨識參考 [官方來源整理](SKYTRAIN_STATION_REFERENCES_2026_10.md)。平面路線來自 repo 封存的 TransLink GTFS 快照；車站保留既有 City of Vancouver 來源身分。班次與時間為離線遊戲模擬，不查詢即時營運、票價或時刻表。

## 使用方式

1. 點「搭乘 SkyTrain」，選起始車站入口及目的地，再按「從這個入口開始」。這是明確的快速開始入口，人物從該站大廳開始步行。
2. 靠近樓梯／電梯通行點，使用「前往月台」或互動鍵。目的地決定路線與方向；Waterfront 的兩條線有分開的空間。
3. 走近正確側車門，等列車停妥、車門完全開啟後上車。大廳、遠處、錯線／錯方向與關門狀態不能上車。
4. 每個中途站停靠時都能下車；留在車上會在停站等待後續行。到目的地或轉乘站時，列車等人物明確下車。
5. Waterfront 轉乘需下車、走回通行點、回大廳、前往另一線月台，再候車上車。
6. 下車後返回大廳，靠近出口按「回到街道」。系統重新確認城市地面安全，再恢復一般步行，不沿用地下月台高度。

站內可更改目的地，上車後鎖定。行駛中不能下車、離站、切換交通模式或重新跨站進入；小地圖及城市直接飛往操作也不能繞過限制。

## 桌機與手機

| 操作 | 桌機 | 手機／觸控 |
| --- | --- | --- |
| 步行 | W／S 前後、A／D 轉向，亦支援方向鍵 | 左下搖桿，前後行走、左右轉向 |
| 環顧 | 拖曳場景 | 在搖桿外拖曳場景 |
| 通行點、上車、下車 | E 或對應按鈕 | 右下互動按鈕 |
| 選行程／離站 | 面板選單／大廳出口按鈕 | 展開面板後使用相同操作 |

入口預設為精簡按鈕；搭乘中桌機顯示完整面板，手機預設顯示目前站／下一站、路線與狀態，可展開行程。按鈕至少 48px，主要觸控動作至少 56px。開門停站時標頭顯示所在站，行駛時顯示下一站。

E 長按不重複互動。編輯表單／選單時不接管行走鍵；點擊場景恢復畫布焦點。Escape 收起輔助面板，不把移動中的乘客送回城市環繞視角。搖桿與環顧分別管理指標，另一根手指點互動不會解除步行。取消指標、失去 capture、失焦、分頁隱藏、停用或卸載介面都會清理按住狀態；回到前景不補跑背景時間。

## 模型與路徑的精確程度

- 七站使用既有原創站體布局、入口、月台、樓梯／扶梯／電梯通行點、障礙與可行走三角形。官方站圖與照片用來研究辨識差異；尺寸、深度、材料、內部配置是代表性重建，沒有現場測量或攝影測量，也未完整複製所有商店、設備及出入口周邊。
- 街道高度取實際城市地形，整站朝向依保留的 GTFS 平面切線調整。Expo 每端保留 **75m**、Canada **65m** 的水平直線接站段，再以寬緩的 C2 接合連入區域路線；地下高度依城市地形約束隧道與列車淨空，保留精確停靠位置／方向。軌道深度與坡度仍是遊戲幾何，不是軌道工程測量。
- 列車逐節沿各自弧長位置轉彎，不再把整組列車當成一根剛體。Expo 四節中心偏移為 26.85／8.95／−8.95／−26.85m，Canada 兩節為 ±10.5m。乘客相機、內裝與燈跟隨搭乘車廂；進站恢復精確直線編組後才驗證月台與開門。Expo 外殼共用單節實例幾何，金屬門框與透明門玻璃使用相同車節變換。
- Expo 使用 Mark V 風格端車內裝與原創四節外觀，並非真實完整五節 Mark V 的逐節重建。Canada 第二節共用原始幾何並保持反向車廂的開門側對應。相機固定於站立位置，未開放車內自由步行、選座或跨車廂。
- Main Street–Science World 執行原點取雙向 GTFS 月台端點中點。公開動線接東入口／樓梯；來源西側支線仍保留於 metadata，目前不接人物步行圖。這是遊戲整合範圍，不表示現實西入口關閉。
- 樓梯可連續步行；指定通行點也能互動切換大廳／月台。電梯通行受距離及樓層限制，未模擬完整機械、隊列或升降動畫。
- 行駛時間依執行曲線長度／11.5m/s 計算並限制在 30–180 秒，另有候車與停站等待；加減速及停站時間為遊戲節奏。速度讀值使用實際曲線長度，供 Auto 畫質判斷移動情境。
- 新站體沒有打包第三方照片、影片、官方站圖像素或來源貼圖。來源範圍見 [來源摘要](qa/skytrain-travel-20261022/network-source-summary.json)。

## 城市幾何接合

地下視角依相機高度與當地地形判定；實際繪製期間暫時隱藏城市共用海面，避免水平海面穿過地下站。正常或失敗繪製後都恢復原先可見狀態。

Main Street 有兩項獨立的材質修正：

- 活躍站體以 source `osm-structure-303` 的 seed 783 加 170m 世界半徑替換重疊的通用站殼。
- City buildingId **133436** 的粗略 GIS 實心外殼與原始 GTFS 高架路權相交。只對該來源 profile 的 seed 967，在 Main 站座標 **X −6.8…6.7m、Z −83.6…−45.7m**、世界高度約 **11.640…16.040m**（軌道 −0.4…+4m）開出有限路權。這約 38m 的局部修正保留街面、上層裙樓／高塔、遠處相同 seed 建築與其他來源，不整棟隱藏高樓。

兩項修正只在 Main 站體活躍／提前準備期間啟用，換站、離站、錯誤或銷毀時清除。原始建築、碰撞、飛行體積及站體資料不變。路權修正在建物主要顯示材質中裁切；保留的深度／陰影等其他繪製通道不能由 CPU predicate 測試推論為同樣裁切。實際畫面另以對應來源版本驗收。

## 效能與資源

首次進站讀取七站輕量 metadata，共 540,255 bytes 未壓縮 JSON；場景只建立一個站體 GPU owner。出發站隱藏、行駛進度超過約 15% 後，用目的站替換並回收來源站。目的站載入後先保持隱藏，預編譯完成才顯示，因此在未覆蓋的末段到來前已有月台／緩衝隧道。人物站點與列車位置仍以實際行駛為準；若抵站時準備未完成，列車停妥關門等待，不提前下車。到站沿用同一 owner；晚到、取消、銷毀與失敗重試受生命週期限制。

進站、換線與目的站準備會預編譯完整城市場景，使世界、車廂及站燈各計入一次，並準備城市材質的新光照組合。暫時可見只限同步收集光照的呼叫內，等待非同步結果前就恢復原狀；未編譯完的目的站不暴露給實際畫面。這降低首次顯示才編譯的機會，不代表零停頓。

當前路段才建立代表性隧道，切段／到站／離站會回收。隧道略過兩端前 32m，約 8m 採樣使第一個中心落在 32–40.1m，與 Canada 47m 的站台／緩衝隧道重疊。完整車節、相機及交界另有實際 `TubeGeometry`／站體三角形稽核。

站體合併／實例化重複幾何，裝飾密度按載入品質決定。車廂 Balanced／相容模式用既有 LOD1，High／Ultra 用 LOD0；載入或換線時固定，不因 Auto 小幅變動而反覆換模型。城市 Auto 仍調整解析度與準備預算，搭乘時使用列車實際速度、站內使用步行情境；手動畫質保留。不同 GPU／手機的效能需看實測，不由 CPU 測試推定。

卸載移除事件、站體、列車與隧道資源。原始 GLB 保持不變，門口開口只調整搭乘實例。重複共享的資源由單一 owner 回收；路線缺失、重複或方向不正確時拒絕開始旅程。
