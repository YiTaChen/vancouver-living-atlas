# Titan 市區路口碰撞與噴流修正

2026-10-22（Vancouver），開發分支 `codex/rocket-launch-game`。

此頁保留 commit `9c70820` 的歷史實作與驗收。道路地基、有限時間擠壓與倒塌碰撞處理已由後續修正更新；目前行為與擴大驗收請見 [Titan 地基、真實接觸與事故回饋](FOUNDATION_CONTACT_FEEDBACK.md)。下方數字仍屬原版本，未當成新版重跑結果。

## 原因與修正

先前完整箭體與外掛助推器直到離地才開始檢查城市碰撞。寬約 28 m 的 Titan 若在路口搭建時已碰到低樓，可能在第一個飛行步進（0.0167 秒、約 0.69 m/s）直接整箭破裂；碰撞沒有傳遞實際撞點給建築。道路表面與放置高度的取樣差異也會讓基座埋入路面。

現在控制器沿用既有城市碰撞幾何，辨識真正碰到的建築 polygon、橋梁或地標，把撞點、速度、質量與表面範圍先交給破壞效果，再判斷火箭反應。受撞建築會先出現可讀的幾何變形、焦黑與來自撞點的碎片。地面放置與噴流接地都採用實際道路高度。

地面／平台搭建時已經重疊的建築，只在低於 25 m/s、離地低於 18 m、飛行不超過 2.5 秒，且離地後該接觸累積不超過 2.5 秒時使用擠壓反應；火箭損失動量與結構強度，弱樓可被推垮。完整強牆、橋梁、新碰撞與高速撞擊仍然會讓火箭墜毀。這是遊戲中的有限接觸模型，並不保證狹窄地點都能安全起飛。

建築因噴流壓垮時，即使火箭尚未碰過該棟建築，後續碰撞也會先同步下沉後的高度，避免撞上已經消失的舊屋頂。所有高度修改只屬於這次火箭任務；城市原始碰撞資料、其他載具和回城後的資料不受修改。

## 實際可見的破壞

建築主體之外，High／Ultra 的額外立面與地標 instance 也會跟著變形和焦黑。玻璃及夜間發光使用任務專用材質處理，避免原本 shader 蓋過受損顏色。

每次繪製暫時套用的幾何、材質及 instance matrix 都在繪製後還原原本所有權；任務結束、修復城市及 LOD 更換時釋放副本。較遠的未受損頁面不會佔住鄰近真撞點的配額。

## 五股噴流與沿地面擴散

核心與四枚外掛仍同時點火。Titan 的五股噴流改為有體積的幾何外殼及亮色內核，帶有隨時間向下流動的湍流與明暗節點。外層保留橘色邊緣，避免五股加色重疊成純白長塊；低推力及上面級切換時，火焰始終連在實際噴嘴。

近地噴流撞上當地道路後，40 條火舌沿地表向外攤開，棕色卷塵沿水平方向加速、阻力減速並上捲。卷塵在既有粒子池內獲得最多 40% 的暫時保留槽，避免被持續產生的引擎／樹火粒子立即覆寫。停止接地後不再產生新卷塵，既有卷塵可繼續消散；箭體起火或事故優先取回全部粒子槽。

四枚外掛先燃盡並向外脫落，核心繼續推進；之後核心才分離，由上面級飛向太空。搭建 16 秒、倒數 5 秒，以及原有飛行與分級參數沒有改動。

| Titan 建築主體部件      | 96，真撞點可替換未受損候選                                             |
| 其他實際接觸表面        | 額外最多 8 組局部範圍                                                  |
| 立面／地標繪製副本      | 含主體輕量 shell 共 32 個 mesh；細節最多 31 個，優先鄰近真撞點與發射點 |
| 非共用細節頂點          | 240,000；主體共用原有屬性，不複製整座城市                              |
| instance 傷害屬性與處理 | 總計 4,096 槽；過大的群組保留原本呈現                                  |
| 五股立體噴流            | 合計低於 13,000 triangles、共用兩種材質、不投射額外陰影                |
| 地面火舌                | 40 條、1 次 instanced draw                                             |
| 粒子                    | compatible 240／balanced 360／high・ultra 600；卷塵共用原池            |

以上是資源預算，不是手機實機 FPS 保證。

## 本輪驗收

驗收使用獨立無頭 Chrome／Metal，不操作使用者正在看的瀏覽器。[可重跑腳本](../../tools/rocket-intersection-acceptance.mjs)從 production `roadGraph` 選擇真實路口，以實際可拾取路面及原控制器放置／Auto 發射，呼叫原始 `update(1/60)`。不指定高度、起火、損壞計數、飛行階段或成功結果。

Balanced 包含兩個開闊路口、兩個外掛與低樓重疊的窄路口，以及一個核心也接觸低樓的路口。High／Ultra 另檢查三類代表地點與立面呈現。每張畫面在實際繪製後量測頂點位移，而不僅是受損計數。各次驗收保存執行前後來源 SHA，拒絕把 HMR 或中途修改來源的結果當作最終證據。

原始診斷中第一個飛行步進的立即破裂是精確的 state 證據；診斷快轉時沒有每個步進繪製，因此同一時點的舊 GPU buffer 位移不能視為自然 60 FPS 同步渲染的破壞量。本輪以繪製後的樣本為準。固定步進驗收同樣不代表真實牆鐘飛行時間或即時 FPS。

最終結果：**11／11 次自然升空至 100 km**；Balanced 五點、High 三點、Ultra 三點，各品質 **18／18 條條件**，合計 **54／54** 通過。三次最終來源 SHA 均一致，任務期間 HMR 為零，未捕捉的 JavaScript 錯誤與 WebGL shader 錯誤均為零。

| Balanced 真實路口           | 起始接觸     | 到達太空的模擬飛行秒數 |
| --------------------------- | ------------ | ---------------------: |
| Jervis／Robson              | 開闊         |                 69.600 |
| Bute／Robson                | 開闊         |                 69.500 |
| Bute／Rosemary Brown Lane   | 外掛碰低樓   |                 69.467 |
| Jervis／Rosemary Brown Lane | 外掛碰低樓   |                 69.583 |
| Burrard／Robson             | 核心也碰低樓 |                 69.683 |

Bute／Rosemary 原失敗位置在點火後 0.5 秒、1.5 秒與首個飛行步進，實際繪製的建築頂點座標最大變化分別為 **0.745／3.535／4.898 m**，隨後繼續升空。這些是幾何位移量，不是損壞計數。High／Ultra 的真實 `Facade reveals and balconies` 頁面也量到焦黑與位移；地標 instance 另有單元 fixture，城市樣本沒有覆蓋具名地標大樓。

繪製後樣本的卷塵中心最遠約 **146 m**，Balanced 最多 96 顆存活卷塵，High／Ultra 樣本最多 147 顆；各型總粒子上限不變。所有 11 次回城後，建築 position／color 原始位元 hash 與基線相同。繪製副本最多觀察到 Balanced 4、High 21、Ultra 23 個，均低於固定預算。

自然事件順序驗證為核心與外掛一起點火 → 四外掛釋放 → 核心單獨推進 → 核心分離 → 上面級點火 → 任務完成。側助推器分離期間，四側噴流全部關閉、主噴流仍可見，核心仍相連且推力大於零。
