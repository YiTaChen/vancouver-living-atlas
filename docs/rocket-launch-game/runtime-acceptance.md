The rocket environment acceptance run passed all 18 checks on October 22, 2026, using Google Chrome with Metal GPU rendering at `http://127.0.0.1:5173/?inspect&graphics=compatible`. The loaded city contained 7,794 building volumes and 35,535 trees.

These are **accelerated runtime tests**. The browser repeatedly called the production `RocketController.update(1 / 60)` and rendered between batches. Construction, countdown, ignition, fuel consumption, manual steering, collisions and the complete ascent were exercised. The tests never assigned a successful phase or a 100 km altitude. This supplements the separate natural-time ascent acceptance run.
