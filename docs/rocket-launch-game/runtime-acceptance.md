The current two-stage rocket environment acceptance run passed **21 of 21 checks** on October 22, 2026, using Google Chrome with Metal GPU rendering at `http://127.0.0.1:5173/?inspect&graphics=compatible`. The loaded city contained 7,794 building volumes and 35,535 trees. The [retained JSON report](runtime-report.json) records the assertions and observed state.

These are **accelerated runtime tests**. The browser repeatedly called the production `RocketController.update(1 / 60)` and rendered between batches. Construction, countdown, ignition, first-stage fuel consumption, booster separation, upper-stage ignition, manual steering, collisions and the complete ascent were exercised. The runner never assigned a successful phase or a 100 km altitude. The flight times below are simulated seconds from liftoff, excluding construction and countdown; they are not the runner's wall-clock duration.

The final clean pass recorded zero uncaught JavaScript errors. HTTP 404 console messages are recorded separately in the raw report. Development-reload and automated setup debugging attempts are excluded from the retained evidence. The final runner waits for React mode changes between successive world-coordinate missions and waits for the nonmodal Space observation region before capturing completed missions. Screenshots are written outside the repository until the browser closes, preventing the development watcher from interrupting the run.

Reproduce the 21 checks with `node tools/rocket-browser-acceptance.mjs` using the [committed runner](../../tools/rocket-browser-acceptance.mjs). Run the complete suite without `ROCKET_QA_RESUME`; that variable is only for continuing an existing local report. The script expects Playwright, the project's supported Node runtime, Google Chrome at its standard macOS installation path, and the development server on port 5173. It writes the new report to `work/rocket-environment-qa.json` and copies the seven retained integration screenshots only after closing the browser.
