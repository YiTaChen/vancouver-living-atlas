# Vancouver · Living Atlas

An original browser-based 3D geographic reconstruction of Vancouver's Downtown peninsula, Stanley Park and False Creek through Science World. Built with TypeScript, Three.js, React and public geographic source data. No Unreal Engine or prebuilt city models.

## Development

Requires Node.js 22.13+.

```sh
npm ci
npm run dev
npm run build
```

## Manager loop

Every milestone is implemented, inspected, reviewed and revised before release. Progress and evidence are recorded in `docs/PROGRESS.md`; each stage is committed and pushed to this public repository.
